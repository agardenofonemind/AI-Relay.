# Handoff Archive

Store important, finalized handoff records in this directory.

## Naming

Prefer the handoff ID and a short topic, for example:

`HO-20261122-01-protocol-review.md`

## Record contents

Use HANDOFF_TEMPLATE.md as the source template. Preserve:
- Related task ID and handoff direction.
- Final conclusions and accepted/rejected recommendations.
- Artifact trust labels and the evidence supporting them.
- Outstanding disagreements or follow-up tasks.
- Links to relevant files, commits, and deliverables.

Do not archive every conversational message. Keep records that preserve a decision, review, implementation result, or context needed for future work.
